Architecture

  • A user enters a URL (www.example.com) into a web browser (Google Chrome) using a computer (client).
  • The web browser (using the URL) sends a DNS query to a DNS server requesting the IP address associated with the URL.
  • DNS server translates the URL into an IP address and sends the information back to the web browser.
  • The web browser uses the IP address to send an HTTP request to the wen server hosting that IP.
  • The web server responds with the webpages requested. (GeeksforGeeks)
