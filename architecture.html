Process-Based Web Servers vs. Event-Driven Web Servers

Process-Based Web Servers

  • Some web servers like Apache use a process-based approach for client requests. As an example, you enter a URL on your phone web browser and the same URL on your laptop web browser. An Apache server will receive both request and send it to an avaliable processing module. Each processing module will independently work the request.
  • According to LiteSpeed, this approach can increase memory usage which causes the site to slow down or may take longer to load the webpage (Technologies, LiteSpeed)

    • Event-Driven Web Servers

  • Web servers like LiteSpeed use an event-driven approach to handle requests. This web server handles all request in one process/fewer processes that a process based server. "New request coming in and new dynamic responses ready to go out" (Technologies, LiteSpeed).
  • If you're entering a URL on your phone and laptop an event driven web server will use one worker to handle the monitoring and response of both connections.
