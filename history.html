Project to Reality

The World Wide Web was developed by Tim Berners-Lee who wanted to create an automated information-sharing platform to connect 17,000 scientist across 100 countires("A Short History of the Web"). The first web server and browser became avaliable in 1990, info.cern.ch is the address and the first webpage hosted is http://info.cern.ch/hypertext/WWW/TheProject.html.(A Short History of the Web"). The initial web server was only avaliable on NeXT computer platforms until Nicola Pellow, a work placement student, developed software for a "line-mode browser" that allowed the web server to run on any machine (A Short History of the Web").


Further Developments

In April of 1993 Berners-Lee, with the permission of CERN, opened the source code for the WorldWideWeb so that other developers could further develop the software at no cost. (A Short History of the Web). 1994 is known as the "Year of the Internet" because after the release of the source code in 93 more developers became intrested and but the end of the year the web had 10,000 web servers and 10 million users (A Short Histor of the Web).

Web Servers in the 90's

Apache server was released in 1995 and is a free open source software where users can build and host their own websites (Mesh Flinders, Ian Samlley) Apache gained popularity as a web server because it is open source, it is compatible with many different OS like MacOS, Linux, and Windows.


Microsoft IIS(Internet Information Services) developed by Microsoft and released in 1995. It is a porprietary of Microsoft and users are not able to access or modify the source code. Integrated perfectly with Microsoft products, and offers built in security features(GeeksforGeeKs).


Jigsaw Server was developed by W3C and released in 1996. Jigsaw server is open source and was mainly designed for testing, and developing web standards(GeeksforGeeks). Jigsaw server is also compatible with multiple OS (Windows, Linux, MacOS)(GeeksforGeeks).


Apache Tom Cat Server developed by Apache Software Foundation and released in 1998 was developed to support Java based applications(GeeksforGeeks).Included enhanced performance and scalability(GeeksforGeeks).

Web Server in the 2000's

LiteSpeed developed by LiteSpeed Technologies and released in 2003(GeeksforGeeks). LiteSpeed server is open source designed to offer less overhead and higher performance than Apache(LiteSpeed). LiteSpeed also added in DDoS protections and offers intelligent cache acceleration (LiteSpeed).
Nginx Web Server developed by Igor Sysoev and released in 2004 is an open source web server built for high performance, speed, and scalability(GeeksforGeeks).
Open LiteSpeed developed by LiteSpeed Technologies and released in 2013 is an open source web server(GeeksforGeeks). This server offers "built in caching", and offers easy to use interface for server configuration"(GeeksforGeeks).
